## 🎬 장면

당당의 핵심은 **"식사 시작 → 1시간 뒤 '혈당 잴 시간이에요' 알림"**이다. 알림이 안 오면 데모가 안 된다.
그런데 우리는 앱스토어 앱이 아니라 **PWA**다. 웹사이트가 어떻게 잠금화면에 알림을 띄우지?

## 🗺 PWA = 웹사이트 + 세 가지

앱스토어 심사도, Swift·Kotlin도 없이 **React + Vite 그대로** 만든다. 화면 쪽은 `vite-plugin-pwa` 플러그인 + 설정 몇 줄이면 된다.

<Callout type="주의">**iPhone은 홈 화면에 추가한 PWA에서만 웹 푸시가 온다.** Safari 탭으로 열면 안 온다. 그래서 개발 계획 M2(10/13~19)에 실제 iPhone으로 먼저 시험(스파이크)한다.</Callout>

## 🛠 스파이크 순서 (버리는 폴더에서)

1. `npm create vite` (react-ts) → `vite-plugin-pwa` → Vercel 배포(폰은 HTTPS 필요)
2. iPhone에서 홈 화면에 추가 → 알림 권한 → 구독 확인
3. VAPID 키 만들고, 처음엔 작은 스크립트로 푸시 → 다음에 Spring 엔드포인트로
4. **잠금화면 알림 캡처** = 성공. 안 되면 대안(알림톡 등)을 바로 정한다

<Callout type="요약">PWA = 웹 + 명함(manifest) + 당직(Service Worker) + 허가증(HTTPS). iPhone은 홈 화면 추가 필수. 받는 쪽은 프론트, 보내는 쪽(VAPID·예약·발송)은 백엔드.</Callout>
