## 🎬 장면

골드상 팀 주소 `github.com/mil-zip`를 열면 사람 프로필이 아니라 **팀 간판**이 나온다.
간판 아래에 서비스 소개, 수상 내역, 팀원, 기술 뱃지가 있고, 그 아래에 저장소가 `milzip-be`, `milzip-fe`, `milzip-etl`로 나란히 있다.

심사위원이 링크 하나만 눌러도 **"아, 이 팀은 이런 서비스를 이렇게 나눠서 만들었구나"**가 한눈에 보인다. 우리도 이걸 만든다.

## 🗺 당당 Organization 구성

| 저장소 | 무엇 | MIL.ZIP에서는 |
|---|---|---|
| `.github` | Org 첫 화면 README(`profile/README.md`), 공통 이슈·PR 템플릿 | `mil-zip/.github` |
| `dangdang-fe` | React 19 + Vite + TS PWA | `milzip-fe` |
| `dangdang-be` | Spring Boot 4.1 API | `milzip-be` |
| `dangdang-ai` | FastAPI AI 보조 + **공공데이터 적재 스크립트** | `milzip-etl` 역할을 겸함 |

<Callout type="핵심">이름 규칙은 **`서비스명-역할`**. 저장소 목록에서 정렬했을 때 나란히 붙어서 보인다.</Callout>

## 🛠 1. Organization 만들기 (웹)

1. github.com 오른쪽 위 **＋** → **New organization**
2. 플랜에서 **Free** → *Create a free organization*
3. 입력
   - **Organization name**: 정한 이름 (예: `dangdang-gdm`). 주소가 `github.com/이름`이 된다. 소문자·하이픈 추천
   - **Contact email**: 학교 메일
   - **This organization belongs to**: *My personal account*
4. 사람 확인(퍼즐) → 약관 동의 → **Next**
5. 멤버 추가 화면은 일단 **Skip** 해도 된다 (아래에서 따로 초대)

<Callout type="주의">Organization 이름은 나중에 바꿀 수 있지만, 바꾸면 저장소 주소가 전부 바뀐다. 처음에 승민 언니랑 정하고 만든다.</Callout>

## 🛠 2. 팀원 초대·권한

1. Org 페이지 → **People** 탭 → **Invite member**
2. 승민 언니 GitHub 아이디 입력 → 역할 **Owner** → *Send invitation*
3. 언니가 메일이나 github.com/notifications에서 **수락**해야 들어온다
4. Org **Settings → Member privileges → Base permissions**를 **Write**로
   - 나중에 들어오는 Member도 저장소에 바로 push·PR할 수 있다

| 역할 | 할 수 있는 것 |
|---|---|
| Owner | Org 설정, 저장소 생성·삭제, 멤버 관리 — **두 명 다 Owner** |
| Member | Base permissions만큼 (Write면 push·PR) |

## 🛠 3. 저장소 4개 만들기

Org 페이지 → **Repositories** → **New repository**

| 칸 | 넣을 것 |
|---|---|
| Owner | **Org 이름**으로 되어 있는지 꼭 확인 (개인 계정으로 잡혀 있으면 안 됨) |
| Repository name | `.github` / `dangdang-fe` / `dangdang-be` / `dangdang-ai` |
| Visibility | **Public** (무료 Org의 비공개 저장소는 브랜치 보호 규칙을 못 건다) |
| Add a README file | ✓ 체크 → 바로 clone해서 시작 가능 |
| .gitignore | fe: `Node` / be: `Gradle` / ai: `Python` / .github: 없음 |

만든 뒤 내 컴퓨터로 받기:

```bash
cd ~/04_Dev
git clone https://github.com/dangdang-gdm/dangdang-be.git
cd dangdang-be
git remote -v        # origin이 Org 주소인지 확인
```

## 🛠 4. Org 첫 화면 README

1. `.github` 저장소 → **Add file → Create new file**
2. 파일 이름 칸에 `profile/README.md` (슬래시를 치면 폴더가 생긴다)
3. 내용은 옵시디언 `13_당당 초기 세팅 가이드` 5절 틀을 붙여 넣는다
   - 순서: 한 줄 소개 → 수상 내역 → 해결하려는 문제 → 서비스 개요 → 주요 기능 → 핵심 기술 → 아키텍처·ERD·시연 → 저장소 링크 → 팀원 → 기술 뱃지
4. 저장 후 `github.com/Org이름`에 들어가서 보이는지 확인

<Callout type="요약">웹에서 Org 만들기 → 언니 Owner 초대 → Base permission Write → 저장소 4개(Public, README 체크) → `.github/profile/README.md`</Callout>
