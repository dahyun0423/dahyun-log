## 🛠 2. 일부러 실패시켜 보기

```bash
./gradlew bootRun
```

아마 이런 에러가 난다:

```text
Failed to configure a DataSource: 'url' attribute is not specified
and no embedded datasource could be configured.
```

## 🛠 3. 다음에 넣을 도구 (하나씩, 이해하면서)

| 도구 | 비유 | 언제 | 커밋 |
|---|---|---|---|
| PostgreSQL 드라이버 | 차트실 출입증 | 지금 | ➕ Dependency/Plugin |
| docker-compose (postgres+pgvector, redis) | 차트실·호출벨 설치 | 지금 | 🔧 Settings |
| Actuator | 맥박 체크 `/actuator/health` | 지금 | ➕ |
| springdoc (Swagger) | 신청서 견본집 | 이번 주 | ➕ |
| Flyway | 선반 설계도(테이블 변경 기록) | ERD 확정 후 | ➕ · `V1__init.sql` |
| Security + JWT | 신분증 확인 | 카카오 로그인 | ✨ Feat |
| Redis | 호출벨 예약 | 알림 | ✨ Feat |

그다음 첫 API: `GET /api/health` → `ok`. 브라우저에서 `localhost:8080/api/health`가 뜨면 **요청 → 서버 → 응답** 한 바퀴를 직접 돌린 거다.

<Callout type="주의">Boot 4는 3.x와 바뀐 게 있다(Jackson 3 `tools.jackson.*`, 일부 starter 이름). 블로그의 3.x 예제를 그대로 복사하지 말고 공식 문서를 먼저 본다.</Callout>

<Callout type="요약">build.gradle=장보기 · gradlew=같은 버전 실행기 · application.yaml=설정표 · Application.java=전원. 첫 실행은 DataSource 에러가 정상 → DB 띄우고 주소 적기. MySQL → PostgreSQL 확인.</Callout>
