## 🎬 장면

입원 팔찌를 아무에게나 빌려주면, 그 사람이 내 이름으로 진료를 받을 수 있다.
비밀번호·DB 주소·API 키는 **한 번 새면 지울 수 없다.** 바꿀 수만 있다.

## 🗺 비밀이 새는 다섯 길

| 길 | 실제 있었던 일 / 예 |
|---|---|
| **채팅·메신저** | 사이트 비밀번호를 대화창에 두 번 |
| **로그·에러 메시지** | 연결 테스트 에러에 DB 주소(비밀번호 포함)가 그대로 출력 |
| **코드·커밋** | `.env.local`을 실수로 커밋 (`.gitignore` 확인) |
| **스크린샷·화면 공유** | 대시보드·터미널 캡처에 값이 찍힘 |
| **복사해 준 요청** | Copy as cURL, HAR에 로그인 쿠키 |

## 🗺 좋은 비밀번호

- **길게**: 짧은 숫자보다 긴 문장이 훨씬 세다
- **어디에도 안 쓴 것**: 다른 사이트와 같으면 한 곳만 털려도 다 털린다
- **기억 말고 관리자에**: 비밀번호 관리자(예: macOS 암호 앱)가 만들고 기억하게

## 🛠 노출됐을 때 순서

1. **바꾼다** (Supabase → Reset database password, `vercel env rm` 후 `add`)
2. 새 값이 들어간 곳을 전부 갱신 (Vercel 환경 셋, `.env.local`)
3. **재배포** 후 로그인·DB 확인
4. 옵시디언 공부일지에 "어디로 샜는지" 한 줄
