## 🎬 장면

수술 영상을 백 번 봐도 직접 봉합을 해 보지 않으면 손이 안 나간다.
AI는 아주 좋은 조수지만, **당당 회의실에서 PR을 merge하는 건 내 손**이다.

## 🗺 나누기

| 맡겨도 되는 일 | 내 손에 익혀야 하는 일 |
|---|---|
| 반복 코드 초안, 오타 찾기 | 브랜치 만들기 · 커밋 나누기 · push |
| 처음 보는 에러의 원인 후보 찾기 | PR 올리기 · base 확인 · **merge 방식 고르기** |
| 문서 요약, 표 정리 | 환경 변수 등록 · 배포 확인 |
| 리서치 초안 | 승민님 PR 리뷰하기 |
| | 개발자 도구로 직접 진단하기 |

<Callout type="주의">"뭔지 모르겠으니 대신 해 줘"는 **배울 기회를 넘기는 말**이기도 하다. 모를 때일수록 "같이 하면서 설명해 줘"로 바꿔 말하면, 다음엔 혼자 할 수 있다.</Callout>

## 🛠 매주 루틴

- **월**: 이번 주 직접 할 PR 하나 정하기 (작은 것)
- **그 PR은 처음부터 끝까지 내 손**: 브랜치 → 커밋 → push → PR → base 확인 → merge 방식 고르기 → 배포 확인
- 막히면 그 화면을 캡처해서 묻고, 답을 들은 뒤 **내가 다시 누른다**
- AI가 해 준 일은 옵시디언에 3줄: 무엇을 / 왜 / 다음엔 내가 어떻게
