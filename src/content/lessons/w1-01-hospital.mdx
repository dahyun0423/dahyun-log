## 🗺 증상으로 위치 짐작하기

| 증상 | 의심할 곳 | 왜 |
|---|---|---|
| 글자가 겹치고 버튼이 깨진다 | 접수창구(프론트) | 화면 그리기 문제 |
| 눌러도 아무 반응이 없다 | 의뢰서 또는 진료실 | 요청이 안 갔거나 진료실이 실패 |
| 저장됐다는데 새로고침하면 사라진다 | 진료실 → 기록실 | DB에 실제로 안 들어감 |
| "불러오는 중"에서 멈춘다 | 진료실 ↔ 기록실 연결 | 내가 겪은 504가 이거였다 |
| 사이트 자체가 안 열린다 | 건물(서버) | 서버가 꺼졌거나 배포 실패 |

<Callout type="주의">"안 돼요"보다 "화면은 멀쩡한데 저장 응답이 안 와요"가 훨씬 빨리 고쳐진다. 증상을 위치로 나눠 말하는 게 첫 기술이다.</Callout>

## 🛠 손으로

1. 이 페이지에서 **⌥⌘I**(윈도우는 F12)로 개발자 도구를 연다
2. **Network** 탭 → 오른쪽 노트에 한 글자 치고 **Enter**
3. `w1-01-hospital`이라는 요청이 생긴다. 이게 이 사이트의 **의뢰서**다
4. 클릭해서 **Payload**(보낸 의뢰서)와 **Response**(받은 답장)를 열어 본다

자세한 개발자 도구 사용법은 🧰 기초 트랙 → 개발자 도구에 있다.
