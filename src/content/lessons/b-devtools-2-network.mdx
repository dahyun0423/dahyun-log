## 🎬 장면

Network 탭은 **창구와 진료실 사이를 오가는 의뢰서 전부의 복사본**이다.
"요청이 갔나? 답이 왔나? 몇 초 걸렸나?" — 여기 다 있다.

## 🛠 손으로 — 노트 저장 의뢰서 잡기

1. **⌥⌘I** → **Network** 탭
2. 위쪽 필터에서 **Fetch/XHR** 클릭 → 이미지·글꼴은 빠지고 API 요청만 남는다
3. 오른쪽 노트에 한 줄 쓰고 **Enter**
4. 목록에 `b-devtools-2-network`(이 카드의 노트 id) 요청이 생긴다. 줄을 보면:

| 칸 | 뜻 |
|---|---|
| Name | 경로 끝부분 (어떤 차트) |
| Status | 상태 코드 (200? 401?) |
| Type | fetch |
| Time | 걸린 시간. 1초 넘으면 의심 |

5. 그 줄을 클릭 → 오른쪽에 탭이 열린다

| 탭 | 보는 것 |
|---|---|
| **Headers** | 메서드, 주소, 상태, 쿠키 같은 귀퉁이 메모 |
| **Payload** | 내가 **보낸** 내용 (의뢰 내용) |
| **Response** | 서버가 **돌려준** 내용 (답장) |
| **Timing** | 어디서 시간이 걸렸나 (서버 대기 = Waiting for server response) |

## 🛠 알아두면 좋은 체크박스

- **Preserve log**: 페이지를 옮겨도 목록이 안 지워진다 (로그인 → 이동 과정 볼 때)
- **Disable cache**: 저장된 옛 파일 말고 매번 새로 받는다
