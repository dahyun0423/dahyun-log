## 🎬 장면

터미널 = **말로 일하는 접수창구**. 버튼 대신 글자로 시킨다.
대부분의 사고는 "내가 지금 **어느 폴더**에서 **무엇을** 쳤는지" 모를 때 난다.

## 🛠 매일 쓰는 10개

| 명령 | 뜻 | 예 |
|---|---|---|
| `pwd` | 지금 어디? | `/Users/limdahyun/04_Dev/github_study` |
| `ls` | 여기 뭐 있어? | `ls -a`는 숨김 파일(.env.local)까지 |
| `cd 폴더` | 이동 | `cd ..`은 한 칸 위로, `cd ~`는 집으로 |
| `mkdir 이름` | 폴더 만들기 | |
| `cat 파일` | 파일 내용 보기 | `cat package.json` |
| `open .` | 지금 폴더를 Finder로 | |
| `clear` 또는 ⌘K | 화면 지우기 | |
| ↑ / ↓ | 전에 친 명령 다시 부르기 | |
| **Ctrl+C** | 실행 중인 것 멈추기 | dev 서버 끄기 |
| `which 명령` | 그 명령이 어디 설치돼 있나 | `which node` |

## 🗺 결과 읽기 — 성공했나?

- 아무 말 없이 다음 줄로 넘어가면 대개 **성공**
- `error`, `fatal`, `not found`, `denied`가 보이면 **실패** → 그 줄을 그대로 복사해 둔다
- 여러 줄을 붙여 넣었으면 **한 줄씩 결과를 확인**한다. 특히 git은 `git status`, `git log --oneline -3`으로 눈으로 본다

<Callout type="주의">모르는 명령은 붙여 넣기 전에 한 번 읽는다. 특히 `rm`(삭제), `--force`, `sudo`가 들어 있으면 멈추고 뜻부터 확인한다.</Callout>

## 🛠 손으로

```bash
pwd                         # 1) 어디?
cd ~/04_Dev/github_study    # 2) 이 사이트 폴더로
ls -a                       # 3) .env.local, .git이 보이나?
npm run dev -- -p 3123      # 4) 사이트 켜기 → 브라우저로 확인
# 5) Ctrl+C 로 끄기 → ↑ 눌러 4번 다시 부르기
```
