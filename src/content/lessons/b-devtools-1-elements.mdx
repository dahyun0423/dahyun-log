## 🎬 장면

개발자 도구 = **병원의 엑스레이**다. 겉(화면)만 보지 말고 속(HTML·CSS·요청)을 찍어 본다.
아무것도 망가뜨리지 않는다. 바꿔도 **내 화면에서만, 새로고침하면 원래대로**.

## 🛠 여는 법 (맥 기준)

| 단축키 | 열리는 곳 |
|---|---|
| **⌥⌘I** | 개발자 도구 (마지막에 보던 탭) |
| **⌘⇧C** | 요소 고르기 모드 — 화면을 눌러 그 요소로 바로 이동 |
| **⌥⌘J** | Console 탭 |

윈도우는 F12, Ctrl+Shift+C, Ctrl+Shift+J.

## 🛠 손으로 — 3분 실습

1. **⌘⇧C**를 누르고 이 레슨 제목을 클릭 → 왼쪽에 `<h1 ...>`이 파랗게 선택된다
2. `<h1>` 안의 글자를 더블클릭해서 아무 말로 바꿔 본다 → 화면 제목이 바뀐다
3. 오른쪽 **Styles** 칸에서 `font-size` 값을 클릭해 숫자를 바꿔 본다
4. 사이드바의 파란 점(노트 쓴 레슨)을 골라 **Styles**에서 `background-color`를 찾는다 → `var(--primary)`가 보인다
5. **새로고침(⌘R)** → 전부 원래대로 돌아온다

<Callout type="핵심">Elements에서 바꾼 건 **내 브라우저 메모리**에만 있다. 진짜로 바꾸려면 코드(`globals.css` 같은 파일)를 고쳐야 한다.</Callout>

## 🗺 Styles 칸 읽는 법

- 위에 있는 규칙일수록 **이긴다** (나중에 적용된 것)
- 줄이 그어진 값 = 다른 규칙에 **져서** 적용 안 된 값
- `var(--primary)` 같은 변수는 클릭하면 실제 색이 보인다
- **Computed** 탭 = 최종적으로 적용된 값만 모아 보기
