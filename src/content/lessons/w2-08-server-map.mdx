## 🎬 장면

로컬에서 서버가 켜지면 나만 볼 수 있다. 폰으로, 멘토님이, 사용자가 들어오려면 **인터넷에 늘 켜져 있는 컴퓨터**가 필요하다.
그게 클라우드 서버다. **AWS EC2**를 빌린다. 사진 창고(S3)도 AWS라 한 곳에서 관리한다.

## 🛠 AWS에서 할 일 (순서)

**0. 돈 사고 막기 — 제일 먼저**
- AWS 가입 → **Billing → Budgets**에서 월 예산(예: 3만 원) 넘으면 메일 알림
- 루트 계정에 **MFA**, 평소에는 루트 말고 **IAM 관리자 사용자**로 로그인

**1. EC2 만들기** (콘솔 오른쪽 위 리전: **서울 ap-northeast-2**)
- 이미지: **Ubuntu LTS** · 유형: **t3.medium**(2코어·4GB, Spring+AI+DB+Redis용) · 디스크: gp3 30GB
- 키 페어: 새로 만들고 `.pem`은 내 맥에만 (`chmod 400`)

**2. 보안그룹** (= 방화벽)
- 22: **내 IP만** · 80·443: 모두 · 그 외 전부 닫기

**3. 탄력적 IP** 할당 → 이 인스턴스에 연결 (재시작해도 주소 고정)

**4. IAM 역할** `dangdang-ec2-s3`: 당당 버킷만 읽기·쓰기 → 인스턴스에 연결. 그러면 서버에서 **S3 키 없이** 접근한다

**5.** ssh 접속(`ssh -i key.pem ubuntu@탄력적IP`) → Docker 설치 → `docker compose version`

**6. 손으로 한 번 배포**: 이미지 받아서 `docker compose up -d` → `http://탄력적IP/actuator/health`

**7.** 도메인 연결 → Nginx → `certbot`으로 HTTPS

**8.** 그다음에 자동화(CI/CD)

> 콘솔에서 한 설정은 캡처와 함께 옵시디언 `08_서버 인프라 가이드`에, 서버 안에서 친 명령은 레포 `infra/server-setup.md`에 남긴다. 나중에 서버를 옮길 때 빠지는 게 없게.

<Callout type="주의">**12/9 발표가 끝나면** EC2 · 탄력적 IP · 스냅샷을 지운다. 탄력적 IP는 안 써도 요금이 나간다.</Callout>

```bash
# 5. 서버에서 (Ubuntu)
sudo apt update && sudo apt install -y docker.io docker-compose-v2 nginx
sudo usermod -aG docker $USER   # 다시 접속하면 sudo 없이 docker
sudo timedatectl set-timezone Asia/Seoul
```

```nginx
# 7. /etc/nginx/sites-available/dangdang  (certbot이 443 부분을 채워 준다)
server {
    server_name 도메인;
    root /var/www/dangdang;              # React 빌드 결과
    location / { try_files $uri /index.html; }
    location /api/ { proxy_pass http://127.0.0.1:8080; proxy_set_header Host $host; proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for; proxy_set_header X-Forwarded-Proto $scheme; }
}
```

```bash
sudo certbot --nginx -d 도메인   # 무료 HTTPS, 자동 갱신
```

<Callout type="요약">EC2(건물) + 보안그룹 22·80·443(출입문) + Nginx(안내데스크·HTTPS) + compose 컨테이너 5개(진료실). 손으로 한 번 → 그다음 자동화.</Callout>
