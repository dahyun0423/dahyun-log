## 🎬 장면

AI 서버는 **외부 판독실**이다. Spring(원무과)이 "이 사진 무슨 음식이야?"라고 의뢰하면 이름 후보 3개를 돌려준다.
폰 화면은 판독실에 직접 갈 수 없다. 비용과 보안 때문에 꼭 Spring을 거친다.

<Callout type="핵심">AI는 **기록 보조**다. 혈당이 정상인지 판단하거나 권고하지 않는다. 후보를 주면 사용자가 확인하고 저장한다.</Callout>

## 🛠 손으로

```bash
brew install uv                     # 10/15 기준 아직 없음
cd ~/04_Dev/dangdang
git clone https://github.com/dangdang-2026/dangdang-ai.git
cd dangdang-ai && git switch develop
git switch -c feature/initial-setting

uv init                             # pyproject.toml, main.py, .python-version
uv python pin 3.11                  # 이 프로젝트는 3.11
uv add fastapi uvicorn pydantic-settings
```

`main.py`:

```python
from fastapi import FastAPI

app = FastAPI(title="dangdang-ai")

@app.get("/health")
def health():
    return {"status": "ok"}
```

```bash
uv run uvicorn main:app --reload    # http://localhost:8000/health · /docs
```

## 🛠 커밋 전에 꼭

```bash
cat .gitignore | grep -E "^\.env|\.venv"   # 둘 다 있어야 한다. 없으면 추가
git status                                  # .env, .venv/ 가 목록에 없어야 한다
```

`.env.example` (값은 비움):

```dotenv
INTERNAL_TOKEN=          # Spring → AI 서버 호출 확인용
LLM_API_KEY=             # 생성형 AI API 키
DATABASE_URL=            # postgresql://...
```

커밋 순서 추천: `🎉 Start: FastAPI 프로젝트 초기 생성` → `➕ Dependency/Plugin: fastapi, uvicorn, pydantic-settings 추가` → `🔧 Settings: .env.example 추가`

<Callout type="요약">AI 서버 = 외부 판독실(Spring만 의뢰). uv = Python판 npm. uv init → pin 3.11 → add → /health → .env·.venv 커밋 금지 확인.</Callout>
