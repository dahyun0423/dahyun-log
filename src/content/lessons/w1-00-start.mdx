## 한 줄로

**왼쪽(레슨)을 읽고, 오른쪽(노트)에 내 말로 다시 쓴다.** 내 말로 못 쓰면 아직 모르는 거다.

## 이 공간 쓰는 법

- 오른쪽 노트는 노션처럼 쓴다. 빈 줄에서 `/`를 치면 제목·목록·체크박스·코드 블록·표를 넣을 수 있다.
- 입력이 멈추면 **자동 저장**된다. 오른쪽 위에 "저장됨"이 뜨면 끝.
- 저장된 노트는 레포의 `notes/` 폴더에 파일로 남는다. 커밋하면 **내 학습 기록이 git 히스토리**가 된다.
- 레슨과 상관없는 기록(에러 해결, 회고, 아이디어)은 사이드바의 **＋ 새 페이지**로 만든다.
- 사이드바에서 파란 점이 붙은 레슨은 노트를 쓴 레슨이다.

## 9주 동안 무엇을 채우나

당당 개발계획서 기준으로 내 담당은 **기획·디자인·AI 서버·인프라**다. 그래서 공부의 중심도 여기다.

- **서버**: HTTP·REST, 인증(JWT·OAuth), DB
- **인프라**: Docker, Nginx·HTTPS, GitHub Actions CI/CD, 블루그린 배포, 모니터링, 부하 테스트
- **AI 서버**: FastAPI, Structured Output, 임베딩·pgvector, 평가 데이터
- **프론트엔드(부가)**: 이 사이트에 매주 기능을 하나씩 직접 추가하면서 배운다
