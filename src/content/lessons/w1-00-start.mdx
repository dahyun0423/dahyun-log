## 이 공간은 이렇게 씁니다

왼쪽 레슨을 읽고, 오른쪽 노트에 **내 말로** 다시 씁니다. 그게 전부예요.

<FlowSim
  title="공부 한 바퀴"

    { id: "save", label: "자동 저장", sub: "notes/" },

    { at: "write", say: "오른쪽 노트에 미리 깔린 질문에 내 말로 답해요. 빈 줄에서 / 를 치면 제목·체크박스·코드 블록을 넣을 수 있어요." },
    { at: "save", say: "입력을 멈추면 0.8초 뒤 자동 저장돼요. 오른쪽 위에 '저장됨'이 뜨면 끝.", packet: "notes/w1-00-start.json\nnotes/w1-00-start.md" },
    { at: "commit", say: "하루를 마치면 커밋해요. 내 학습 기록이 git 히스토리로 남아요." },
  ]}
/>

<Callout type="핵심">내 말로 못 쓰면 아직 모르는 거예요. 막히면 그 자리에 "모르겠음"이라고 적어두세요. 그것도 기록이에요.</Callout>

- 사이드바에서 **파란 점**이 붙은 레슨은 노트를 쓴 레슨이에요.
- 레슨과 상관없는 기록(에러 해결, 회고)은 **＋ 새 페이지**로 만들어요.
