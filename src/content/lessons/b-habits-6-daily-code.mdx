## 🎬 장면

혈당 관리는 한 번에 크게 하는 게 아니라 **매일 재고 기록하는 것**이다. 당당이 사용자에게 권하는 바로 그 방식이다.
개발 실력도 같다. 주말에 몰아서 8시간보다 **매일 30분**이 이긴다.

## 🗺 왜 매일인가

- 어제 쓴 코드를 오늘 다시 보면 **복습**이 된다 (이 사이트 🔁 복습 퀴즈와 같은 원리)
- 작은 커밋이 쌓이면 **포트폴리오와 GitHub 기록**이 된다
- 막히는 지점이 매일 나와서 **공부할 거리**가 끊기지 않는다

## 🛠 규칙

1. **시간을 고정** — 예) 매일 밤 10시 30분, 30분
2. **크기는 한 문장** — "로그인 실패 시 401 돌려주기", "노트 목록에 빈 상태 문구 넣기"
3. **끝나면 커밋 + 노트 한 줄** — 무엇을 했고 어디서 막혔나
4. **문서는 그다음** — 계획서·발표 자료는 코드 시간 뒤에

### 9주 목표 (제안)

| 주 | 하루 | 주간 커밋 |
|---|---|---|
| 1~3주 | 30분 | 5개 |
| 4~6주 | 45분 | 7개 |
| 7~9주 | 60분 | 7개 이상 |
