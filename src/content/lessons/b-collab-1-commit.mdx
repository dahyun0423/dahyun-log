## 🎬 장면

커밋 = **차트에 한 줄 적는 진료 기록**. "혈당 측정 기능 추가"와 "버튼 색 변경"을 한 줄에 섞어 적으면, 나중에 하나만 되돌리고 싶을 때 곤란하다.

## 🗺 내 컨벤션 (자주 쓰는 것)

| 이모지 | 타입 | 언제 |
|---|---|---|
| ✨ | Feat | 기능 추가 |
| 🐛 | Fix | 버그 수정 |
| 🎨 | Design | 화면·CSS |
| ♻️ | Refactor | 동작은 같고 구조만 개선 |
| 📝 | Docs | 문서·글 |
| 🔧 | Settings | 설정 파일 |

형식: `✨ Feat: 무엇을 했는지 (현재형, 짧게)`

<Callout type="핵심">`git add .`은 "전부 담기"라 섞이기 쉽다. **경로를 적어서** 이번 이야기에 해당하는 파일만 담는다.</Callout>

## 🛠 커밋 후 3초 확인

```bash
git status            # 남은 변경이 있나? (있으면 빠진 커밋이 있는 것)
git log --oneline -3  # 방금 커밋이 맨 위에 있나?
```
