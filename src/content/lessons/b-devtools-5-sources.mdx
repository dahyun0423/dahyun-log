## 🎬 장면

console.log는 **환자에게 "아프면 소리 질러 주세요"** 라고 부탁하는 것. 브레이크포인트는 **환자를 멈춰 세우고 직접 청진기를 대는 것**이다.
코드를 그 줄에서 **일시정지**시키고, 그 순간의 모든 변수를 본다.

## 🗺 브레이크포인트 7종 — 언제 무엇을

| 종류 | 거는 법 | 이럴 때 |
|---|---|---|
| **줄** | 줄 번호 클릭 | 이 줄이 실행되는지·그때 값은? |
| **조건부** | 줄 번호 우클릭 → **Add conditional breakpoint** | `title === ""`일 때만 멈춤 |
| **Logpoint** | 우클릭 → **Add logpoint** | **멈추지 않고** Console에 기록. console.log를 코드에 안 넣어도 됨 |
| **XHR/fetch** | 오른쪽 **XHR/fetch Breakpoints** ＋ | 주소에 `/api/notes`가 들어간 요청이 나갈 때 → **누가 불렀는지** |
| **이벤트** | **Event Listener Breakpoints** → Mouse → click | "버튼 눌렀는데 반응 없음" → 핸들러가 도는지 |
| **DOM** | Elements에서 노드 우클릭 → **Break on** | 이 요소가 바뀌거나 지워지는 순간 |
| **예외** | **Pause on uncaught exceptions** | 에러가 나는 바로 그 순간 |

## 🗺 멈췄을 때 읽는 순서

1. **Call Stack** — 어떤 함수들을 거쳐 여기 왔나 (맨 위 = 지금, 아래로 갈수록 부른 쪽)
2. **Scope** — 지금 이 순간의 변수 값 (Local = 이 함수 안). 더블클릭하면 값을 바꿀 수도 있다
3. **Watch** — **Add watch expression**으로 계속 보고 싶은 식 등록 (예: `editor.document.length`)
4. 한 걸음씩 나아가기

| 버튼 | 단축키(맥) | 뜻 |
|---|---|---|
| Resume | F8 / ⌘\ | 다음 멈춤까지 계속 |
| **Step over** | F10 / ⌘' | 이 줄 실행하고 다음 줄 (함수 안으로 안 들어감) |
| **Step into** | F11 / ⌘; | 이 줄의 함수 **안으로** 들어감 |
| Step out | ⇧F11 / ⌘⇧; | 지금 함수를 끝내고 바깥으로 |
| **Continue to here** | 줄 우클릭 | 그 줄까지 한 번에 |

<Callout type="핵심">React 내부(react-dom)로 자꾸 Step into 되면 그 프레임을 우클릭 → **Add script to ignore list**. 내 코드만 따라간다.</Callout>

## 🗺 그 밖에 현업에서 쓰는 것

- **⌘P**: 파일 이름으로 열기 (`NoteEditor` 치면 바로)
- **원본 코드 보기(소스맵)**: 파일 트리에서 **Authored**(내가 쓴 코드) 쪽을 연다. **Deployed**는 압축된 결과물
- **Overrides**: Network에서 요청 우클릭 → **Override content** → 서버 응답을 내 마음대로 바꿔 화면 시험 (예: 노트 목록을 빈 배열로). 바꾼 요청엔 보라색 점. 켜 두면 캐시가 꺼진다
- **Snippets**: Sources → **Snippets** → **New snippet**. 자주 쓰는 Console 코드를 저장해 두고 **⌘Enter**로 실행

## ⚠️ 초보가 자주 하는 실수

- 브레이크포인트를 걸어 둔 채 잊음 → 페이지가 계속 멈춤. 오른쪽 **Breakpoints** 목록에서 정리
- console.log 수십 개 → **logpoint**로 대신
- 압축 파일(Deployed)을 읽느라 고생 → **Authored**
- 배포본에서 원본 코드가 안 보임 → Next.js는 배포본 소스맵을 기본으로 안 낸다. 로컬(`npm run dev`)에서 재현

## 🛠 손으로 (로컬 localhost:3123, 로그인한 상태)

1. Sources 오른쪽 **XHR/fetch Breakpoints** ＋ → `/api/notes` → 노트에 쓰고 **Enter** → 멈추면 **Call Stack**에서 `save` 함수 찾기 → Scope에서 `titleRef` 값 보기 → **F8**로 계속
2. ⌘P → `NoteEditor.tsx` → `function changed()` 줄에 **Add logpoint** → `'변경됨', dirty.current` → 글자를 칠 때마다 Console에 찍히나
3. **Event Listener Breakpoints → Mouse → click** 켜고 사이드바 **📁** 버튼 클릭 → 어느 함수에서 멈추나 (끝나면 꼭 끄기)
4. Network에서 `/api/notes` 우클릭 → **Override content** → 내용을 `[]`로 → 새로고침 → 홈의 "최근 기록"이 빈 상태 문구로 바뀌는지 (끝나면 Overrides 끄기)
