## 🎬 장면

로그인하면 서버가 **입원 팔찌(쿠키)**를 채워 준다. 그다음부터 의뢰서를 낼 때마다 팔찌가 자동으로 같이 간다.
그 팔찌를 직접 찾아 보자.

## 🛠 손으로 — 내 팔찌 찾기

1. 로그인한 상태에서 **⌥⌘I** → **Application** 탭 (안 보이면 `»` 눌러서)
2. 왼쪽 **Storage → Cookies → 이 사이트 주소**
3. `dahyun_session` 줄을 본다

| 칸 | 내 쿠키 | 뜻 |
|---|---|---|
| Value | 긴 글자 | 서명된 증표. 서버만 진짜인지 알 수 있다 |
| Expires | 30일 뒤 | 이때까지 로그인 유지 |
| **HttpOnly** | ✓ | 자바스크립트로 못 읽음 |
| **Secure** | ✓ (배포) | HTTPS로만 보냄 |
| **SameSite** | Lax | 다른 사이트에서 몰래 보낸 요청엔 안 실림 |

4. **Console**에서 `document.cookie`를 쳐 본다 → `dahyun_session`이 **안 보인다**. HttpOnly라서다

<Callout type="핵심">HttpOnly 덕분에, 혹시 사이트에 나쁜 스크립트가 끼어들어도(XSS) 팔찌를 훔쳐 갈 수 없다. 그래서 로그인 증표는 localStorage가 아니라 HttpOnly 쿠키에 둔다.</Callout>

## 🗺 쿠키 vs localStorage

| | 쿠키 | localStorage |
|---|---|---|
| 서버로 자동 전송 | ✓ 요청마다 | ✗ |
| JS로 읽기 | HttpOnly면 ✗ | ✓ |
| 이 사이트에서 | 로그인 증표 | 사이드바 폴더 펼침 상태 (`page-tree-open`) |

**Local storage → 이 사이트 주소**를 열면 `page-tree-open`이 보인다. 폴더를 접었다 펴면 값이 바뀐다.
