## 한 줄로

**Docker는 "내 컴퓨터에서 되는데요"를 없애는 도구다.** 프로그램과 실행 환경을 통째로 상자에 담아서 어디서든 똑같이 실행한다.

## 이미지와 컨테이너

| | 뜻 | Java에 빗대면 |
|---|---|---|
| 이미지 | 실행 환경이 담긴 설계도 (예: `postgres:16`) | 클래스 |
| 컨테이너 | 이미지를 실제로 실행한 것 | `new`로 만든 객체 |

하나의 이미지로 컨테이너를 여러 개 띄울 수 있다. 클래스 하나로 객체를 여러 개 만드는 것과 같다.

## 첫 컨테이너: Postgres

```bash
docker run --name dangdang-db \
  -e POSTGRES_PASSWORD=devpass \
  -e POSTGRES_DB=dangdang \
  -p 5432:5432 \
  -v dangdang-data:/var/lib/postgresql/data \
  -d postgres:16
```

| 옵션 | 뜻 |
|---|---|
| `--name` | 컨테이너 이름 |
| `-e` | 환경 변수 (비밀번호, 처음 만들 DB 이름) |
| `-p 5432:5432` | **내 컴퓨터 포트 : 컨테이너 포트** 연결 |
| `-v 이름:경로` | 볼륨. 컨테이너를 지워도 데이터가 남는 저장 공간 |
| `-d` | 백그라운드로 실행 |

접속해 보기:

```bash
docker ps                                          # 실행 중인 컨테이너 목록
docker exec -it dangdang-db psql -U postgres -d dangdang
```

`psql` 안에서 `CREATE TABLE test (id serial, memo text);` → `\dt`로 테이블을 확인하고 `\q`로 나온다.

## 여러 개를 한 번에: docker-compose

당당은 Postgres(pgvector 포함)와 Redis가 같이 필요하다. 매번 `docker run`을 두 번 치는 대신 파일 하나로 적는다.

```yaml
# compose.yaml
services:
  db:
    image: pgvector/pgvector:pg16
    environment:
      POSTGRES_PASSWORD: devpass
      POSTGRES_DB: dangdang
    ports: ["5432:5432"]
    volumes: [db-data:/var/lib/postgresql/data]
  redis:
    image: redis:7
    ports: ["6379:6379"]
volumes:
  db-data:
```

```bash
docker compose up -d     # 전부 켜기
docker compose ps        # 상태 보기
docker compose down      # 전부 끄기 (볼륨은 남음)
```

## 직접 해보기

1. 위의 `docker run`으로 Postgres를 띄우고 테이블을 하나 만든다
2. `docker rm -f dangdang-db`로 지운 뒤 같은 명령으로 다시 띄운다. 테이블이 남아 있나? (볼륨 덕분)
3. 당당 레포에 `compose.yaml`을 만들어 db와 redis를 한 번에 띄운다 — **이건 내가 직접 쓴다**
4. 막힌 에러는 ＋ 새 페이지로 "에러 기록" 페이지를 만들어 남긴다
