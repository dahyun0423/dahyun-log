## 🎬 장면

계획서에는 "간호사·경험자 현장 검증 네트워크"라고 썼다. 이제 진짜로 물어볼 차례다.
멘토링 전에 **들은 말 그대로**를 들고 가야 한다. 지어낸 결과는 안 들고 간다.

## 🗺 무엇을 확인하나 (가설)

| # | 가설 | 맞으면 | 틀리면 |
|---|---|---|---|
| H1 | 식후 측정 시각을 **놓치거나 헷갈린** 적이 있다 | 식사 시작 → 알림이 핵심 | 알림보다 기록에 집중 |
| H2 | 종이·메모·사진 등 기록이 **흩어져** 있어 진료 때 보여 주기 번거롭다 | 리포트가 중요 | 리포트 단순화 |
| H3 | 병원에서 들은 기준(목표·측정 시점)이 **사람마다 다르다** | 기준 직접 입력(R1) 유지 | 다시 논의 |
| H4 | 먹은 음식을 적는 게 **제일 귀찮다** | 사진·이름 검색 보조 | AI 비중 축소 |

## 🗺 누구에게

| 대상 | 관점 | 확인할 것 |
|---|---|---|
| 산부인과 간호사 (엄마) | 진료실 | 임당 환자에게 실제로 하는 안내, 진료 때 보는 기록 모양·시간 |
| 간호사 (이모) | 의료진 | 환자가 자주 헷갈리는 것, 앱이 하면 안 되는 말 |
| 임당 경험자 (이모) | 사용자 | 하루 측정 루틴, 놓친 순간, 기록 방법, 산후 검사 |
| (가능하면) 지금 임신 중인 사람 | 사용자 | 지금의 불편 |

## 🛠 질문 바꾸기

| ✗ 유도·미래 질문 | ✓ 과거 행동 질문 |
|---|---|
| 알림 있으면 편하시겠죠? | 마지막으로 식후 혈당 잴 때, 시간을 어떻게 기억하셨어요? |
| 기록 앱 쓰실 것 같아요? | 측정한 숫자는 어디에 적으셨어요? 지금도 남아 있어요? |
| 진료 때 리포트 보여 주면 좋겠죠? | 진료실에서 기록을 보여 드린 적 있어요? 어떻게 보여 주셨어요? |
| 음식 기록 귀찮으시죠? | 어제 저녁 먹은 걸 적으셨다면, 어떻게 적으셨어요? |

질문 끝에는 늘 **"그때 어떠셨어요?" "왜요?"** 를 한 번 더 붙인다.

## 🛠 기록 형식 (한 사람당 한 장)

```text
날짜 / 대상(관계·관점) / 방식(대면·전화) / 시간
- 들은 말 그대로 (따옴표)
- 놀란 점
- 가설 H1~H4: 맞음 / 틀림 / 모르겠음 + 근거 문장
- 기능에 반영할 것 (아이디어, 확정 아님)
```

<Callout type="주의">**들은 말만 적는다.** 인터뷰를 못 했으면 "못 함"이라고 적는다. 그럴듯한 결과를 지어내면 계획서와 발표의 근거가 전부 무너진다. 의료 판단(이 수치면 괜찮다 등)은 앱에 넣지 않는다는 원칙도 같이 확인한다.</Callout>
