## 🎬 장면

진료실에서 "주사 놨어요"와 "주사 놨고, 10분 뒤 혈압 재 보니 정상이에요"는 다르다.
개발도 **실행**과 **확인**이 한 쌍이다.

## 🗺 실제로 있었던 다섯 번

| 내가 한 말 | 실제 상태 | 짝이 되는 확인 |
|---|---|---|
| 커밋 다섯 개 "이거까지 했어" | 두 개 빠짐 | `git status`, `git log --oneline -5` |
| 비밀번호 등록 "했어" | 없음 (두 번) | `vercel env ls` |
| DB 주소 "했어" | Direct 주소 → 앞 공백·끝 잘림 | `node --env-file=.env.local scripts/check-env.mjs` |
| PR "너가 하라는대로 해봤어" | 받는 쪽이 main | PR 화면 맨 위 `base:` 한 번 보기 |
| 배포 "다 된 것 같고" | 배포 사이트 비밀번호가 달랐음 | 배포 주소에서 직접 로그인 |

<Callout type="핵심">문제는 실수가 아니라 **확인 없이 다음으로 넘어간 것**이다. 실수는 누구나 한다. 확인하는 사람은 3초 만에 찾는다.</Callout>

## 🛠 확인 루프 3단계

1. **실행** — 명령 하나
2. **확인** — 짝이 되는 확인 명령 / 화면 한 곳
3. **보고** — "했어 — (확인 결과 한 줄)"

### 자주 쓰는 짝

| 작업 | 확인 |
|---|---|
| git commit | `git status` 비었나 · `git log --oneline -3` |
| git push | `git status -sb`에 `[ahead]`가 없나 |
| 환경 변수 | `vercel env ls` · 점검 스크립트 |
| 배포 | 배포 주소에서 바뀐 화면 직접 보기 |
| PR | base·compare, "Able to merge" |
| DB 저장 | 새로고침해도 남아 있나 |
