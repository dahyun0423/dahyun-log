## 🛠 막힌 곳 6개

| # | 화면에 뜬 말 | 원인 | 해결 |
|---|---|---|---|
| 1 | 'Budgets'가 안 보임 | 콘솔이 한국어라 이름이 **'예산'** | 검색창에 `예산` |
| 2 | 보안 자격 증명: '콘텐츠를 불러올 수 없음' | 새 AWS는 **프로젝트 방식** — 루트로 직접 들어가지 않는다 | MFA는 계정 메뉴 › **프로필** › 보안 |
| 3 | 서울 리전 사용 불가 | Free 플랜 프로젝트는 **가입 때 리전(시드니) 하나만** | Paid 업그레이드 + **고급 기능 활성화** (관리 계정 이메일은 AWS에 안 쓴 메일) |
| 4 | `explicit deny in a service control policy` | 조직 정책(SCP) `RegionFloor` 허용 목록에 서울 없음 | 관리 계정 › Organizations › 정책 편집 → `"ap-northeast-2",` **한 줄 추가** |
| 5 | AMI ID가 유효하지 않음 | 미리 골라진 이미지가 **시드니용** | Ubuntu를 다시 클릭 |
| 6 | 아시아 태평양(서울) 리전 제한됨 | 콘솔 **표시되는 리전**에 서울 없음 | 통합 설정 › 계정 설정 › 표시되는 리전에 서울 체크 |

<Callout type="주의">**고급 기능 활성화는 되돌릴 수 없고 지출 한도가 사라진다.** 그 뒤로는 $20 예산 알림 메일이 유일한 경보. 학교·개인 메일 스팸함까지 본다.</Callout>

## 🛠 서버 안에서 친 것 (그대로 다시 쓸 수 있게)

```bash
# 내 맥: 키 정리 + 단축키
mv ~/Downloads/dangdang-key.pem ~/.ssh/ && chmod 400 ~/.ssh/dangdang-key.pem
# ~/.ssh/config 에 추가
# Host dangdang
#   HostName 43.203.51.14
#   User ubuntu
#   IdentityFile ~/.ssh/dangdang-key.pem
ssh dangdang

# 서버
sudo timedatectl set-timezone Asia/Seoul
sudo apt-get update
sudo apt-get install -y docker.io docker-compose-v2 nginx certbot python3-certbot-nginx
sudo usermod -aG docker ubuntu
sudo systemctl enable --now docker nginx

# 가비아 DNS: A @ → 43.203.51.14, A www → 43.203.51.14 (몇 분 만에 퍼짐)
dig +short dang-dang.site          # 43.203.51.14 나오면 OK

# Nginx 사이트(/etc/nginx/sites-available/dangdang) 만들고
sudo nginx -t && sudo systemctl reload nginx
sudo certbot --nginx -d dang-dang.site -d www.dang-dang.site --redirect
```

```nginx
server {
    server_name dang-dang.site www.dang-dang.site;
    root /var/www/dangdang;                       # React 빌드가 들어갈 자리
    location / { try_files $uri $uri/ /index.html; }
    location /api/ { proxy_pass http://127.0.0.1:8080; }          # Spring
    location = /actuator/health { proxy_pass http://127.0.0.1:8080; }
    # 443·인증서 부분은 certbot이 자동으로 채워 줬다
}
```

## 🗺 확인한 것

| 확인 | 결과 |
|---|---|
| `http://dang-dang.site` | 301 → https로 넘김 |
| `https://dang-dang.site` · `www` | 200 🔒 (Let's Encrypt, 자동 갱신) |
| `/actuator/health` | 502 — **아직 Spring을 배포하지 않아서 정상** (다음: 자동 배포) |
| dangdang-be 로컬 | Postgres로 바꾸고 테스트 통과, Docker 이미지 health **UP** |

<Callout type="요약">새 AWS는 '프로젝트 방식' → 서울을 쓰려면 업그레이드·고급 기능·SCP·표시 리전 4단계. EC2는 t3.medium·암호화·22는 내 IP·탄력적 IP. 서버엔 Docker·Nginx, 도메인은 가비아 A 레코드, HTTPS는 certbot 한 줄.</Callout>
