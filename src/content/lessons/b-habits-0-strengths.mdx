## 🎬 장면

이 카드 묶음(🪞 내 개발 습관)은 **나를 진찰하는 차트**다. 진단은 근거가 있어야 하니까, 칭찬도 고칠 점도 **실제로 있었던 일**로만 적었다.

## 🗺 근거가 있는 강점 다섯 개

| 강점 | 근거 (실제 기록) | 개발에서 무기가 되는 곳 |
|---|---|---|
| **원하는 걸 사용자 행동으로 말한다** | "엔터 누르면 저장되는 느낌", "노션처럼", "옵시디언처럼 폴더 안에 여러 페이지", "› 누르면 접히게" | 완료 기준·테스트 시나리오를 바로 쓸 수 있다 |
| **막히면 원문을 붙여 넣는다** | `vercel env add` 출력, GitHub 화면 문구를 그대로 가져옴 | 디버깅 속도. 좋은 질문의 절반 |
| **기록 습관** | 옵시디언 6개 프로젝트·175개 문서, 공부일지 | 회고·PR 설명·포트폴리오가 저절로 쌓인다 |
| **근거를 확인한다** | 계획서 수치를 원문과 대조해 '약 6배' → '2.78배'로 고침 | 공식 문서로 확인하는 개발 습관과 같은 근육 |
| **결정이 빠르다** | 배포·DB·디자인 방향을 바로바로 결정 | 막혔을 때 선택지를 오래 붙잡지 않는다 |

<Callout type="핵심">기획을 해 본 개발자는 드물다. "무엇이 완료인가"를 사용자 입장에서 정할 수 있다는 건 큰 무기다. 다음 카드들은 이 무기를 **끝까지 확인하고, 직접 손으로 해내는** 쪽으로 다듬는 이야기다.</Callout>
