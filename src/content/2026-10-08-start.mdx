## 당당에서 내가 맡은 것

개발계획서의 역할 분담 기준으로 내 담당은 **기획·디자인·AI 서버·인프라**다.

- **AI 서버**: FastAPI, 음식 이름 후보(Structured Output), 진료 메모 정리, 근거 검증기, pgvector 음식명 매칭, 평가 데이터
- **인프라**: EC2·S3, Docker·Nginx·HTTPS, GitHub Actions CI/CD, 블루그린 배포, 모니터링, 부하 테스트, 백업
- **프론트**: 디자인 시스템, 상태 화면 QA, 사용성 개선
